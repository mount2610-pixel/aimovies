# AIMOVIES

aimovies.mn сайтын код.

## Файлын бүтэц

```
aimovies/
├── index.html      ← хуудасны араг яс
├── css/style.css   ← өнгө, хэмжээ, загвар
├── js/data.js      ← КИНОНЫ МЭДЭЭЛЭЛ (ихэвчлэн зөвхөн үүнийг засна)
├── js/app.js       ← товч, слайд, хайлт гэх мэт үйлдэл
└── images/         ← бүх зураг
```

## Ажиллуулах

VS Code дээр хавтсаа нээгээд `index.html` дээр баруун товч → **Open with Live Server**.

## Шинэ кино нэмэх

1. Зургаа `images/` хавтсанд хийнэ (жишээ нь `shine-kino.jpg`, 16:9 эсвэл өргөн хэлбэртэй).
2. `js/data.js` нээгээд нэг киноны `{ ... },` блокийг хуулж, доор нь буулгана.
3. `id`-г давхцахгүй тоогоор, бусад мэдээллийг өөрийнхөөрөө солино.
4. Хадгална (Ctrl + S).

## Зураг солих

Одоо байгаа зургууд дизайны дэлгэцийн зургаас тайрсан түр зургууд. Эх зургуудаа **яг ижил нэрээр** `images/` хавтсанд хуулж солиход хангалттай.
Дээд талын том слайдад өргөн зураг (1920×800 орчим) тавих бол `data.js` дотор тухайн кинонд `hero: "зургийн-нэр.jpg"` гэж нэмнэ.

## Видео нэмэх (дараа нь)

Bunny Stream-д видео оруулсны дараа өгөх embed холбоосыг кинонд нэмнэ:

```js
video: "https://iframe.mediadelivery.net/embed/....",
```
